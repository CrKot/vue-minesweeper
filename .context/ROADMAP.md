# Roadmap

## Уже сделано

- Vue 3 + TypeScript + Vite приложение.
- Игра "Сапер" с уровнями сложности.
- Safe first click.
- Таймер.
- Флаги.
- Счетчик оставшихся флагов.
- Итеративное открытие пустых областей.
- Реактивная сетка, корректная при смене сложности.
- Горизонтальный скролл для широкого поля.
- Убраны основные магические числа из логики.
- Убраны односимвольные имена переменных в проектном коде.
- Добавлены тесты на основные компоненты и composable.
- Добавлены тесты на `GameStatus`, win/lost и ограничения флагов.
- Добавлены базовые keyboard/ARIA-атрибуты для ячеек и статус-бара.
- Цвета ячеек, чисел и статус-бара вынесены в CSS-переменные.
- README обновлен под реальный проект.

## Ближайшие полезные задачи

1. Добавить ARIA-label для кнопок управления сложностью.
2. Добавить рекорды в `localStorage`.
3. Улучшить мобильный UX hard-поля.
4. Добавить E2E-тесты для полного сценария игры.
5. Добавить chording: открытие соседей кликом по открытому числу.

## Идеи фич

- Перезапуск по клику на emoji статуса.
- Выбор кастомного размера поля.
- Счетчик лучших результатов по сложности.
- Подсветка неверно поставленных флагов после проигрыша.
- Chording: клик по открытому числу открывает соседей, если вокруг стоит нужное количество флагов.

## Риски

- Сейчас нет e2e-тестов, только unit/component tests.
- Проект не в git, поэтому откаты и просмотр diff сложнее.
